WHAT IS A CLAUDE SKILL?
A skill is a folder with a SKILL.md file: a name, a one-line description of when to use it, and instructions (plus optional reference files and scripts). Claude loads only the name+description until a task matches — then reads the full skill on demand (progressive disclosure). Launched by Anthropic in October 2025.
