WHAT IS MCP?
The Model Context Protocol is an open standard (created by Anthropic, late 2024; adopted by OpenAI and Google in 2025) that lets any AI app talk to any tool through one interface. Servers expose tools, resources, and prompts over JSON-RPC; agents discover them at runtime.
