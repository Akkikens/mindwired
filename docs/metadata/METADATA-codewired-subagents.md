WHAT IS A SUBAGENT?
A subagent is a fresh instance of Claude Code with its own empty context window, defined by a simple markdown file (name, description, allowed tools) in .claude/agents/. It does one job in its own context and returns only the conclusion — keeping your main agent's memory clean.
