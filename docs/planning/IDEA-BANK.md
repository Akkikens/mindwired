# IDEA-BANK — raw material, not yet a topic

Not a topic queue (that's `TOPIC-QUEUE.md`, for Icahn-validated candidates).
This is upstream of that: a running log of interesting facts, angles, or
cross-episode connections noticed during ANY research pass that don't fit
the episode being worked on right now, but might seed or sharpen a future
one. Log it here instead of letting it evaporate at the end of a session.

Add an entry whenever research on episode A surfaces something that's
actually about topic B (a regulatory thread, a shared name, a recurring
mechanism, an unresolved thread another episode's CLAIMS file flagged and
dropped). Review this file when picking the next topic, alongside the
normal Icahn sweep — the sweep finds proven demand; this file is where
genuine cross-topic connections (the kind that make for a distinctive
angle, not a generic retread) actually come from.

Format: one entry per finding — what it is, which episode surfaced it,
why it might matter later. Prune entries once they're used or clearly dead.
