# ATTRIBUTION — TWA Flight 800 (Black Box Breakdown)

Manual pulls (verified assets named in `docs/planning/CLAIMS-twa800.md` §"Archival
Footage Plan", plus follow-up Commons/NTSB/Judicial Watch research). Fetched
2026-08-21 via the Wikimedia Commons API, the DVIDS API, ntsb.gov, and
judicialwatch.org — real User-Agent header, normalized with ffmpeg. Everything
below is PD or CC-licensed; **nothing from CNN/NBC/BBC/Fox or any broadcast-news
source was used anywhere in this episode.**

  that it was not worth the risk despite the PD tag and Coast Guard sourcing.
  Flagging this explicitly rather than silently using or silently skipping it.

## ntsbreport/ (NTSB Aircraft Accident Report AAR-00/03 + Safety Rec Letter)

All rendered via `pdftoppm -png -r 200` from the actual, live-fetched federal
PDFs (Public Domain, US federal government work):

- `ntsbreport_1.jpg` — AAR-00/03 page 326, section "3.2 Probable Cause" —
  exact text quoted in scene c6_1's exhibit citation. Source:
  https://www.ntsb.gov/investigations/AccidentReports/Reports/AAR0003.pdf
- `ntsbreport_2.jpg` — AAR-00/03 page 56, **Figure 17**, "A schematic diagram
  of the 747-100's fuel quantity indication system wiring, fuel flow wiring,
  cockpit voice recorder wiring, and other wiring information" — the actual
  FQIS wiring diagram from the report.
- `ntsbreport_3.jpg` — NTSB Safety Recommendation Letter **A-98-34 through
  -39** (April 7, 1998), page 1 — the letterhead/opening page, exact citation
  match for scene c6_4's exhibit source.
  https://www.ntsb.gov/safety/safety-recs/recletters/A98_34_39.pdf
- `ntsbreport_4.jpg` — AAR-00/03, title/cover page (page 1) — generic
  establishing "this is the official report" cutaway for non-exhibit scenes.
- `ntsbreport_5.jpg` — Safety Recommendation Letter A-98-34/-39, page 2 — the
  detailed findings text naming the specific 747 airframes (N93105, N93117,
  F-BPVE, British Airways G-BBPU) found with damaged FQIS wiring during the
  fleet-wide post-accident wiring examinations.

**Exhibit-pinned duplicates (2026-08-21):** the doc engine cycles a shared
`img` prefix across every scene that uses it, by position — not by which
exact page a scene's `source` citation names. That's fine for the generic
"this is the official report" cutaways above, but the episode's two central
"receipts on screen" beats (the Probable Cause reveal, c6_1; the fleet-wide
wiring-defect reveal, c6_4) need to guarantee their OWN cited page shows, not
whichever page the rotation lands on. So those two scenes were repointed to
dedicated single-purpose prefixes, each an exact byte-identical copy of the
already-documented file above (same source/license, just isolated from the
shared rotation):
- `ntsbcause_1.jpg` — AAR-00/03 page 326, section "3.2 Probable Cause" (same
  file as ntsbreport_1.jpg, isolated to its own prefix so scene c6_1 always
  shows this exact page). Public Domain, NTSB/US federal government work.
  https://www.ntsb.gov/investigations/AccidentReports/Reports/AAR0003.pdf
- `ntsbwiring_1.jpg` — NTSB Safety Recommendation Letter A-98-34 through -39
  (April 7, 1998), page 1, letterhead (same file as ntsbreport_3.jpg, isolated
  so scene c6_4 always shows this exact page). Public Domain.
  https://www.ntsb.gov/safety/safety-recs/recletters/A98_34_39.pdf
- `ntsbwiring_2.jpg` — Safety Recommendation Letter A-98-34/-39, page 2,
  wiring-damage findings (same file as ntsbreport_5.jpg, isolated so scene
  c6_4's pool includes this exact page). Public Domain.
